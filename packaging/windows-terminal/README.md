# Windows 终端宿主修复

适用于与 manifest 精确匹配的 DSH 0.2.1-rc.5 / Windows x64 桌面制品。用于处理终端启动和退出异常，与 DSH 0.2.2 的桌面启动增强组件不同。

该工具创建独立桌面副本，不随 npm 安装静默运行，不修改原安装、用户 Home 或注册表。

## 创建副本

使用 Python 3.12 或更新版本，以及合法取得、哈希符合 manifest 的官方桌面目录：

```powershell
python packaging/windows-terminal/build.py --source "<官方桌面目录>" --destination "<不存在的新目录>"
```

输入输出不得嵌套。目标必须不存在；工具拒绝重解析点，先校验输入及补丁，再复制和应用。失败时保留目标现场，不自动删除或重试。

新副本保留完整性检查，但修改后的程序不保留原代码签名有效性。版本号相同不代表制品哈希匹配，不能强行应用。

输出回执中的 BUILT_NOT_TESTED 只表示构建完成。请在独立环境检查启动、终端命令、退出及重启；不代表全部插件业务通过。

本项目不分发完整官方桌面。请遵守原程序与相关模块许可证，保留许可证文件。未知版本、其他操作系统不在该工具支持范围。
