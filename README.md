# DSH Crate

将 DeepSeek Harness 的环境配置和插件打包为 `.dshcrate`，用于迁移、保存和恢复。第三方社区项目，目前为预览版，兼容性取决于具体宿主和插件组合。

## 模型 API 配置迁移

**模型 API 配置迁移**：在导出页展开高级选项，按需勾选当前 Profile 中的模型服务商。预览列出所选服务商、协议、API 地址、模型、适用的新会话默认模型以及密钥环境变量名。未勾选的服务商不导出；默认模型属于未勾选服务商时也不导出。此选项支持宿主的静态 `llm-pi-ai` 与 `agent-default-model` 配置，不读取全局凭据库，不迁移代理、MCP、自定义认证头或密钥值。

含模型配置的包只支持导入**新环境**。在目标机单独提供预览列出的密钥变量，再启动该环境；预检只能检查变量名是否存在，不能验证其有效性。API 地址须为 HTTPS 或本机回环 HTTP；带认证信息、查询参数、片段或非标准路径的地址会被拒绝，不会被悄悄改写。

## 安装

当前预览版：**`dsh-crate-web@0.1.2-preview.22`**。需要预览功能时请指定完整版本。

Desktop 用户在目标桌面窗口的插件管理中安装上述包，按提示重启后打开 **Settings → DSH Crate**，无需另外启动 Web 实例。

命令行用户将下面的 `web` 替换为实际环境名：

```powershell
dsh plugin --profile web add dsh-crate-web@0.1.2-preview.22
```

全局 npm 安装不能替代安装到 DSH 环境。Windows x64 包包含 Python 运行时。请使用准确包名 `dsh-crate-web`；`dsh-crate` 是其他项目，不是本插件的替代安装名。

## 主要功能

- 导出前预览体积，搜索和筛选插件，选择已安装版本或公共 npm 精确版本。
- 将插件加入包而不安装到当前环境；支持内嵌制品与需要确认的仅引用模式。
- 快速压缩使用 ZSTD 9，紧实压缩使用 ZSTD 19。新导出为 schema 4，兼容读取 schema 1–3；接收端应升级后再导入新格式。
- 新建环境导入支持恢复格式版本 4 包中选定的会话。接收端使用同名会话文件时，导入会停止并保留已有记录。也可向已有环境只新增、更新并合并插件。先预检、预览差异，再确认执行。
- 已有目标导入前快照，导入事务失败时恢复；恢复失败明确提示并保留现场。后续独立功能验证失败不自动回滚。
- 对明确的问题插件提供保留、跳过或手动选版，重新预检后执行；不自动替换为 latest，也不支持任意降级。
- 界面跟随 DSH 中英文与深浅色；完整诊断可查看、复制，并在会话服务可用时转发给选定 Agent。

## Desktop 支持

桌面增强组件后台准备，校验通过后才可启用。修改桌面程序及退出重启需要确认，未知宿主制品不应用补丁。

适配 Windows x64 上的指定 DSH Desktop 构建；版本、哈希及验收边界见[桌面兼容说明](./docs/desktop-compatibility.md)。启用后支持单实例切换、多 Desktop 分别启停、默认环境和确认后替换 desktop；Web 单独管理。运行中的环境覆盖需要协调停机与快照。

插件携带校验过的轻量桌面组件，优先从包内初始化，缺少组件时才使用固定来源下载。准备组件不修改桌面程序；退出、备份、应用和重启仍须确认。仅版本号相同但哈希不同的构建不会自动应用。

新建 Desktop 副本可选择共用 DSH 用户 Skill 和模型凭据库（含 API Key、OAuth），插件目录独立。本机共用不等于将凭据导出。状态恢复与任务继续受宿主支持限制，不保证所有任务自动续跑。

旧版 DSH 0.2.1-rc.5 的独立终端修复见[使用说明](./packaging/windows-terminal/README.md)，不能与上述组件互换。

## 兼容与限制

- 普通迁移功能与桌面增强组件的兼容范围不同；版本声明、安装成功和组件加载正常都不等于插件全部功能可用。
- 自动更新检查仅考虑正式版本，不自动安装，也不将预览版本作为升级目标。手动插件选版与此分开。
- 内嵌插件制品不代表全部依赖和桌面组件都可离线恢复。
- 凭据值不进入迁移包；环境包不是整机镜像。
- PASS 表示具体检查通过；FAIL 为失败；UNTESTED 为未验证；DEGRADED 为存在明确的非阻塞问题。未验证项不能当作兼容承诺。

## 已知问题

- Preview.19 修正空响应与刷新失败的反馈：已完成的导入保留结果；提交后无法确认结果时显示“结果未知”，请核对环境和历史，不要反复覆盖导入。
- 配套桌面组件第二版修复深层 Windows 路径下维护运行器无法启动的问题。已安装旧组件的用户仍需按插件提示确认退出、更新组件并重启。
- 文件占用、权限和宿主初始化异常仍需按具体错误处理，不保证所有环境均可恢复或启动。

请参阅[版本状态](./docs/CURRENT-STATUS.md)和[桌面兼容说明](./docs/desktop-compatibility.md)。反馈问题时提供版本、系统、操作步骤及脱敏诊断，不提交密钥、令牌、个人路径或完整用户目录。
