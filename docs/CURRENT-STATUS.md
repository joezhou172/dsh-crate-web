# 版本状态

当前预览版：`dsh-crate-web@0.1.2-preview.22`。安装与功能见 [README](../README.md)。

## 功能范围

支持环境导出、体积预览、插件选择、新建与增量导入、问题插件手动选版、快照恢复和按宿主条件启用的桌面管理。自动更新仅检查正式版本。

Windows 版可用随包压缩器重建插件。使用 Conda 导入时，如果本机压缩结果与包内记录不同，Crate 会使用随包压缩器重建，再核对清单与插件锁中的 SHA-256。

## 使用限制

- Windows 10、Windows 11 和不同 DSH 制品的行为可能不同，不能由单一组合推断全部兼容。
- 桌面增强组件仅接受已识别的精确宿主制品；未知制品不修改。
- 成功安装、导入或启动不等于所有插件业务功能通过。
- Preview.19 修正导入空响应与刷新失败的反馈；配套桌面组件第二版支持深层 Windows 路径下的维护与恢复。旧组件需要确认退出后更新。

当前安装名保持 `dsh-crate-web`。不要安装其他同名项目来替换本插件。更多限制与反馈方式见 README。
