# 桌面补丁兼容范围

适用于 Preview.20 的桌面增强组件。

## 构建识别

组件 `desktop-multiversion-bootstrap-3` 同时检查桌面版本和原始 `app.asar` SHA-256。仅以下精确构建进入适配范围：

| DSH Desktop | 原始 SHA-256 |
|---|---|
| 0.2.1-rc.5 | `e1b6f25fa937da98086c3e77af77aa14791105963c4d337a1c42179d232c6915` |
| 0.2.2-rc.1 | `5fa8a6b21bceb8f3e99e30efa2270efd0cc773a11e42aa0488f804a64b34e637` |
| 0.2.2-rc.3 | `14cfd81c9135bf0afb89417543c94f9ecfe09266574452a9b106890c698725ae` |

未知版本、不同哈希、变动的原始备份或不匹配的补丁回执均拒绝覆盖。恢复时按回执绑定的准确版本校验，不会使用另一版本的原件。

## 初始化与更新

插件包内携带组件及其校验清单。后台初始化先验证本地组件，必要时才下载固定来源的组件；不会自动选择远端预览版本。独立工作进程使用同一份已验证内容，在用户确认且桌面正常退出后备份程序、应用补丁并重启。多个桌面主进程仍在使用同一安装时，不冒险覆盖程序。

组件准备与补丁安装是两个阶段；界面显示“就绪”不代表已经改动桌面。程序修改后的回执记录实际版本、原件哈希、补丁后哈希和组件标识。

## 适用边界

仅支持上表列出的准确制品；不保证其他操作系统、重打包桌面或正在执行的任务能无缝恢复。
