# 导出预览、插件选择与压缩

Preview.7 提供两条兼容路径：旧请求继续使用原有导出契约；新版界面使用 requestVersion=2 的插件选择与冻结预览计划。

## 新版操作

进入插件二级页可选择插件、搜索和筛选，并选择已安装内容或 registry 精确版本。额外加入的包仅进入导出制品，不安装到源 Profile。仅引用模式先显示确认弹窗，服务端也检查确认。不得取消必要的官方 Bundle 激活要求。

预览通过正式 exporter 生成实际文件，返回体积、分类和最大条目。新版服务端保存冻结文件及计划 ID，绑定请求内容、Profile 和选项，有效期 15 分钟、单次使用。正式下载使用冻结文件，避免预览与下载重新打包产生差异。更改选择或压缩模式后必须重新预览。旧接口没有冻结计划时仍是参考体积，最终大小可能改变。

快速使用 ZSTD 9，紧实使用 ZSTD 19。schema 4 使用版本化的插件传输编码；导入校验传输、tar 内容和安装制品身份，并恢复为 npm tgz。旧 schema 1–3 仍可读取。新包接收端应升级 Crate；不承诺旧版可读取 schema 4。仅引用制品的未来下载大小不计入当前包体积。

## 验证边界

文件级测试覆盖分类求和、计划冻结/草稿绑定/过期与单次使用、插件选择、引用确认、ZSTD 两档往返、损坏制品与资源上限。真实 HTTP/Core 桥接覆盖 registry 下载后仅加入导出，源环境不安装。前端受控测试覆盖语言、主题、筛选与选择保留、诊断复制和错误路径。
